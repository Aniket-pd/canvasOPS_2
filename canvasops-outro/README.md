# CanvasOps outro

A 3.8-second, 1920×1080 Remotion outro built from the CanvasOps product design system.

The CanvasOps layer mark resolves directly into the wordmark and product descriptor.

## Preview

```sh
npm run dev
```

Open the `CanvasOpsOutro` composition in Remotion Studio.

## Render

```sh
npm run render
```

The final H.264 file is written to `renders/canvasops-outro-1080p.mp4`.
